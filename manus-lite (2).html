長期記憶與 Skills

記憶以 Markdown 文字儲存在此瀏覽器。可匯入自己的 .md Skill，模型會在每次任務中看到已啟用 Skill 摘要。

選擇 .md 後會加入下方 Skill 清單；不會上傳到伺服器。

LLM 與工具設定

支援 Gemini 原生 API、OpenAI 相容 API，以及可自訂 Base URL 的模型。API Key 僅由此瀏覽器直接送至你設定的端點。

Gemini 會使用 Google Generative Language API；OpenAI / 自訂模型則呼叫 Base URL + /chat/completions。
支援回傳 JSON 的 API；{query} 會被替換。未設定時使用 DuckDuckGo Instant Answer。
